# ジャッジ原文検索アプリ

ポケモンカードゲームの公式PDF資料からページ単位で原文を抽出し、検索するための静的HTMLアプリです。

## 起動方法

このフォルダでローカルサーバーを起動します。

```powershell
python -m http.server 8793
```

ブラウザで以下を開きます。

```text
http://127.0.0.1:8793/
```

同じWi-Fi内のスマホから見る場合は、PCのWi-Fiアドレスを使います。

```text
http://PCのIPアドレス:8793/
```

例：

```text
http://192.168.0.207:8793/
```

## 現場で使う前の準備

大会やイベント前に、スマホでアプリを開いて `事前保存` を押します。

オフライン利用を安定させる本番運用では、Cloudflare PagesやGitHub PagesなどのHTTPS公開先で一度開き、スマホのホーム画面に追加しておくのが推奨です。ローカルLANの `http://192.168...` は確認用には便利ですが、ブラウザによってはService Workerのオフライン保存が制限されます。

## 紙運用との併用

このアプリは裁定を自動判断するものではありません。

紙資料の代わりではなく、公式PDF原本の該当ページへ速く戻るための索引として使います。検索結果から `PDF原本を見せる` を押すと、公式PDFページをそのまま表示できます。

## 初期MVP

- PDF.jsによるPDF本文抽出
- 全資料検索
- 資料別検索
- ペナルティガイドライン＋裁定事例集検索
- 検索語ハイライト
- PDF該当ページ表示
- ショートカット検索
- お気に入り保存
- PDF.jsのローカル同梱
- PWA用の事前保存

公式資料原文と自分用メモを混ぜない方針で、記録・振り返り機能は次の段階で追加します。
