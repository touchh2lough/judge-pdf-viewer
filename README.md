# ジャッジ用PDFビューアー

ポケモンカードゲームの公式PDF資料を、現場で起きた事象から素早く開くための静的HTML/PWAアプリです。

このアプリは裁定を自動判断するものではありません。表示された項目は資料確認の入口です。

公式PDFは同梱しません。公式サイトからの自動取得、選択したフォルダからの取り込み、手動登録で、自分のブラウザ内に保存して利用します。ジャッジ限定資料は端末内でのみ登録します。

## 起動方法

このフォルダでローカルサーバーを起動します。

```powershell
python -m http.server 8793
```

ブラウザで以下を開きます。

```text
http://127.0.0.1:8793/
```

同じWi-Fi内のスマホから見る場合は、PCのWi-Fiアドレスを使います。

```text
http://PCのIPアドレス:8793/
```

例：

```text
http://192.168.0.207:8793/
```

## 現場で使う前の準備

大会やイベント前に、スマホでアプリを開いて `事前保存` を押します。

オフライン利用を安定させる本番運用では、Cloudflare PagesやGitHub PagesなどのHTTPS公開先で一度開き、スマホのホーム画面に追加しておくのが推奨です。ローカルLANの `http://192.168...` は確認用には便利ですが、ブラウザによってはService Workerのオフライン保存が制限されます。

## 紙運用との併用

紙資料の代わりではなく、公式PDF原文の該当箇所へ速く戻るためのビューアーとして使います。

## 現在の主な機能

- PDF登録とブラウザ内保存
- 事象入口タイル
- ペナルティガイドラインと裁定事例集の表示
- PDF.jsによるPDF表示
- PDF内マーカー表示
- 分類データJSONの読み込み
- 分類データのインポートとリセット
- PDFから検出した未登録項目の表示
- PWA用の事前保存

## PDFの更新・取り込み

下部ナビの「資料」にある「PDFの更新・取り込み」から操作します。検索は画面上部、事象・検索・履歴・お気に入り・資料は下部ナビから直接切り替えられます。「大会前の準備」でオフライン用の事前保存と検索データの再作成ができます。

PDFはページ番号を入力して移動できます。「戻る」、Esc、ブラウザの戻るで閉じると、元の画面とスクロール位置へ戻ります。検索結果は画面切り替え後も保持します。

- 公式PDF：起動時とアプリを開いている間に、1日1回確認します。「今すぐ確認・取得」で任意に確認できます。上級プレイヤー用ルールガイド、競技向けフロアルール、ペナルティガイドライン、裁定事例集の4資料を対象に、公式ページ上の最新リンクを見つけます。
- フォルダ連携：PC版Chrome・Edgeなどで、ダウンロードフォルダまたはPDF専用フォルダを一度選択します。アプリを開いている間、直下の対象PDFを10分ごとに確認します。読み取り許可が切れた場合は「今すぐ取り込み」で再許可します。サブフォルダ・無関係な名前のファイルは対象外です。
- フォルダ連携非対応のブラウザ：対象PDFを複数選択して取り込めます。スマホのDownloadsフォルダを無許可で読むことはできません。
- ジャッジ通信：配布PDFを複数選択して追加します。各号はファイル名をタイトルにし、「ジャッジ通信」フィルターでまとめて検索できます。資料画面で差し替え・削除できます。同じ内容のPDFは改名しても重複登録しません。

公式PDFの自動取得には、`worker/official-updates.mjs` のCloudflare Workerを公開し、`js/update-config.mjs` にURLを設定します。公式サイトにブラウザから直接アクセスするとCORS制限があるためです。Workerは公開4資料を取得する読み取り専用の中継で、PDFのアップロード・保存・ジャッジ通信の取得を行いません。

更新に失敗した場合は旧PDFを維持します。内容のハッシュで変更を判定し、版番号と更新日をPDF本文から抽出します。自動更新では古い版への巻き戻りや想定資料名が確認できないPDFを見送ります。手動登録では確認のうえ登録できます。画像だけのPDFは全文検索できないため、ページ表示で確認してください。

PDF・資料情報・資料ごとの検索索引はIndexedDBにまとめて保存します。旧バージョンの登録済みPDFとlocalStorageの索引は起動時に移行します。更新PDFの解析・保存が成功するまで旧データを置き換えません。閲覧履歴とお気に入りはこれまでどおり保持します。ブラウザのサイトデータを削除するとPDFも削除されるため、原本は各自で保管してください。

## 開発時の検証

```powershell
node --test tests/update-policy.test.mjs
node --check js/app.js
```

`tools/browser-smoke.mjs` はPlaywrightとpdf-libを使い、4種の実PDF・通信のダミーPDFで取り込み、検索、重複防止、フォルダ連携、オフライン、保存失敗時の一括ロールバック、旧ストレージ移行を検証します。公式PDFを `tests/fixtures/` に各公式ファイル名で準備し、`node tools/browser-smoke.mjs --node-modules <パッケージのあるnode_modulesディレクトリ>` で実行します。テストはHeadless Edgeとローカル8793番ポートを使用します。テスト用PDF、画像、WorkerビルドはGitに含めません。
